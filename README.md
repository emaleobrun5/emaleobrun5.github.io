# emaleobrun5.github.io

Páginas públicas de **Fábrica multicuentas**, la herramienta privada que sube y programa videos en los canales de YouTube de su operador: inicio, política de privacidad y condiciones del servicio (en inglés y español).

Las piden Google (pantalla de consentimiento OAuth) y la auditoría de la API de YouTube. Si cambian los permisos que usa la herramienta o cómo guarda los datos, hay que actualizar `privacy.html` antes de pedir el permiso nuevo.

Sitio estático, sin cookies ni analítica, publicado con GitHub Pages en https://emaleobrun5.github.io/.
