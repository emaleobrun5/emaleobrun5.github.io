Privacy Policy

Last updated: November 6, 2026

Fábrica multicuentas (the "tool") is a private publishing tool operated by Emanuel De Leon, in Uruguay. It uploads and schedules videos to YouTube channels owned or managed by its operator. You must agree to this policy before using the tool.

YouTube API Services

The tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's use of data is governed by the Google Privacy Policy.

What we access

When a channel owner authorizes the tool through Google's sign-in screen, the tool receives permission to manage the videos of that channel (scope youtube.upload). It uses that permission only to:

  • upload videos produced by the operator to the authorized channel;
  • set each video's title, description, privacy status, scheduled publication time and, when it applies, the disclosure of altered or synthetic content.

The tool does not read your comments, subscribers, messages, watch history, contacts or any other account data. If it ever needs a new permission (for example, channel analytics), this policy will be updated before that permission is requested.

What we store

  • The authorization token issued by Google, kept on the operator's own computer or server, outside any public code repository, so uploads can run without signing in each time.
  • A publication record: for each video the tool uploaded, its ID, title, status and scheduled time, the ID of the channel that received it, the operator's internal name for that channel, the upload date and a fingerprint (SHA-256 hash) of the uploaded file, so the same video is not uploaded twice. This data is refreshed or deleted at least every 30 days, as required by the YouTube API Services policies.

The tool does not collect data about viewers or about anyone other than the authorizing channel owner.

How we use and share it

The data is used only to publish the operator's videos. It is sent only to Google/YouTube to perform the upload. It is not sold, rented or shared with any other party, and it is not used for advertising.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Cookies and this website

The tool does not place cookies or similar technology on your device and does not let third parties serve content or advertisements through it. This website has no cookies, analytics or ads; it is hosted by GitHub Pages, which may log technical data such as IP addresses as described in the GitHub Privacy Statement.

Revoking access and deleting data

  • You can revoke the tool's access at any time from Google's security settings: https://security.google.com/settings/security/permissions.
  • If access is revoked from the tool, the token is revoked immediately and the related data is deleted within 7 days. If it is revoked from Google's settings, the related data is deleted within 30 days. Tokens are checked periodically, and data tied to a token that can no longer be refreshed is deleted.
  • You can ask for your stored data to be deleted by writing to the contact below; it will be deleted within 7 days.

Children

The tool is not directed to children and is used only by its operator.

Your rights

You can request access to, correction of or deletion of your personal data, as provided by Uruguay's Personal Data Protection Law (Ley N.º 18.331).

Contact

Questions or complaints about privacy: Emanuel De Leon · emaleobrun5@gmail.com

Changes

If this policy changes, the new version is published on this page with a new date.

Política de Privacidad

Última actualización: 6 de noviembre de 2026

Fábrica multicuentas (la «herramienta») es una herramienta privada de publicación que opera Emanuel De Leon, en Uruguay. Sube y programa videos en canales de YouTube que su operador tiene o administra. Para usarla tienes que aceptar esta política.

Servicios de la API de YouTube

La herramienta usa los servicios de la API de YouTube. Al usarla aceptas las Condiciones del Servicio de YouTube. El uso de datos por parte de Google se rige por la Política de Privacidad de Google.

A qué accedemos

Cuando el dueño de un canal autoriza la herramienta desde la pantalla de inicio de sesión de Google, la herramienta recibe permiso para administrar los videos de ese canal (permiso youtube.upload). Lo usa solo para:

  • subir al canal autorizado videos producidos por el operador;
  • poner el título, la descripción, el estado de privacidad y la hora de publicación de cada video y, cuando corresponde, la declaración de contenido alterado o sintético.

La herramienta no lee tus comentarios, suscriptores, mensajes, historial, contactos ni otros datos de la cuenta. Si alguna vez necesita un permiso nuevo (por ejemplo, las estadísticas del canal), esta política se actualiza antes de pedirlo.

Qué guardamos

  • El token de autorización que entrega Google, guardado en la computadora o el servidor del operador, fuera de cualquier repositorio de código público, para que las subidas funcionen sin iniciar sesión cada vez.
  • Un registro de publicaciones: de cada video que subió la herramienta, su ID, título, estado y hora programada, el ID del canal que lo recibió, el nombre interno que el operador le da a ese canal, la fecha de subida y una huella (hash SHA-256) del archivo subido, para no subir dos veces el mismo. Estos datos se actualizan o se borran al menos cada 30 días, como piden las políticas de la API de YouTube.

La herramienta no recoge datos de los espectadores ni de nadie más que el dueño del canal que la autoriza.

Cómo los usamos y con quién los compartimos

Los datos se usan solo para publicar los videos del operador y se envían solo a Google/YouTube para hacer la subida. No se venden, no se alquilan, no se comparten con nadie más y no se usan para publicidad.

El uso de la información recibida de las API de Google cumple con la Política de Datos del Usuario de los Servicios de las API de Google, incluidos los requisitos de Uso Limitado.

Cookies y este sitio

La herramienta no guarda cookies ni tecnologías parecidas en tu dispositivo y no deja que terceros muestren contenido o publicidad a través de ella. Este sitio no tiene cookies, analítica ni anuncios; lo aloja GitHub Pages, que puede registrar datos técnicos como la dirección IP según la Declaración de Privacidad de GitHub.

Quitar el acceso y borrar los datos

  • Puedes quitarle el acceso a la herramienta cuando quieras desde la configuración de seguridad de Google: https://security.google.com/settings/security/permissions.
  • Si el acceso se quita desde la herramienta, el token se revoca en el momento y los datos relacionados se borran dentro de 7 días. Si se quita desde la configuración de Google, se borran dentro de 30 días. Los tokens se revisan cada tanto y se borran los datos de los que ya no se pueden renovar.
  • Puedes pedir que se borren tus datos escribiendo al contacto de abajo; se borran dentro de 7 días.

Menores

La herramienta no está dirigida a menores y solo la usa su operador.

Tus derechos

Puedes pedir el acceso, la corrección o la eliminación de tus datos personales, según la Ley N.º 18.331 de Protección de Datos Personales de Uruguay.

Contacto

Consultas o reclamos sobre privacidad: Emanuel De Leon · emaleobrun5@gmail.com
